## 明確なポリシーを持つプロキシ

Esperanta は HTTP と HTTPS CONNECT のためのフォワードプロキシです。Go で書かれ、設定したアドレスだけで待ち受け、明示した IP 範囲のクライアントだけを受け入れ、接続先ポートとアドレスを制限します。

デーモンは非特権で動作します。Linux では設定を読み込んだ後に、失敗時に閉じる Landlock のファイルシステム・TCP ポリシーを適用します。配布される systemd サービスは `DynamicUser` として動作し、ケーパビリティを持たず、多数のサンドボックス設定が有効になります。

## はじめに

1. APT、COPR、pacman、Snap またはソースから [Esperanta をインストール](/ja/installation)します。
2. ループバック以外へ公開する前に[設定リファレンス](/ja/configuration)を確認します。
3. HTTP / HTTPS クライアントから[プロキシを使用](/ja/usage)します。
4. サービスとして運用する場合は[セキュリティとサンドボックス](/ja/security)を確認します。

## Esperanta が行わないこと

Esperanta はオープンプロキシ、TLS 傍受プロキシ、キャッシュプロキシ、パッケージリポジトリサーバーではありません。HTTPS CONNECT の通信はエンドツーエンドで暗号化されたままで、カスタム上流ヘッダーは通常の HTTP 転送だけに適用されます。
